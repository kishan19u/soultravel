# 🌍 SoulTravel – World Tour Made Simple

## 📌 Project Description
SoulTravel is a travel-based web project designed to help users explore beautiful destinations around the world in a **cost-effective and well-planned manner**.  
The platform focuses on providing curated travel packages, clear itineraries, and an easy enquiry system for users who want stress-free travel planning.

## 🎯 Objective
The main objective of this project is to:
- Help users plan world tours easily
- Provide affordable yet premium travel options
- Offer clear day-wise itineraries and services
- Create a user-friendly travel enquiry system

## ✨ Features
- 🌎 Destination-based travel packages  
- 🗓️ Day-wise travel itinerary details  
- 📩 Request a Callback & Enquiry forms  
- 🧭 Easy navigation and clean UI  
- 💰 Cost-effective tour planning  

## 🧑‍💻 Technologies Used
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js, Express.js  
- **Database:** MySQL  
- **Tools:** VS Code, GitHub
